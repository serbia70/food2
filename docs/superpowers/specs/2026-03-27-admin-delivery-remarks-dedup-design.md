# Admin 外卖备注去重展示 Design

**Goal:** 清理 `/admin/[slug]` 外卖订单卡片里的重复备注展示，只保留地址行中的内联备注，不再额外显示一整块备注面板，也不再提供外卖专用备注按钮。

**Why:** 当前外卖卡片里同一条备注会出现两次：一次在地址行 `(备注:微辣/Mild)`，一次在下方独立“备注”面板里，视觉上显得重复且拥挤。用户已经确认外卖备注是订单自带信息，不需要再单独补一层展示或编辑入口。

## Scope

仅调整外卖订单卡片的备注展示，不改堂食逻辑：

- 外卖卡片保留地址行中的 `(备注:xxx)`
- 删除外卖卡片下方独立备注面板
- 删除外卖卡片操作区里的 `🏷️` 备注按钮
- 堂食桌卡、堂食详情弹窗、堂食备注编辑能力保持不变

## Files

- Modify: `src/components/admin/TabTables.astro`
- Test: `src/pages/master/dine-in-panel-routing.test.ts`

## Design

### 1. 外卖备注只保留一处

外卖订单头部地址行已经包含：

- 联系人
- 电话
- 地址
- 支付方式
- `(备注:xxx)`

这已经足够表达订单备注，不再需要第二块独立 remark panel。删除下方 `remark-ui` 区块后，卡片结构会更紧凑，商品列表与操作区之间也更清晰。

### 2. 移除外卖备注按钮

外卖卡片操作区当前有一个 `🏷️` 按钮，会让人误以为需要再次添加/编辑备注。既然备注已内联展示，且本次目标是避免重复信息，则该按钮应一并移除。

注意：这里只移除外卖卡片里的 `order-remarks` 按钮；堂食的 `table-remarks` 按钮不变。

### 3. 保持堂食现状

堂食场景下，备注依然需要：

- 从详情入口查看
- 从堂食备注入口维护

因此这次不动 `table-management.ts` 的堂食详情备注渲染，也不改 `AdminModals.astro` 的备注弹窗。
