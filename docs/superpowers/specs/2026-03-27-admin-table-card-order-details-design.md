# Admin 桌卡订单详情入口设计

## 目标
在 `/admin/[slug]` 的堂食桌卡上补一个不增行的“订单详情”入口，让管理员能直接查看该桌订单的菜品、数量、金额和备注。

## 现状
- 堂食桌卡底部已经有 4 个主操作：点餐、结账、修改、备注。
- 当前桌卡上没有订单详情入口。
- 订单备注没有丢，已经存在于订单数据里，但堂食桌卡没有展示链路。
- 现有代码里已经有可复用的订单详情弹窗逻辑：`src/scripts/admin/table-management.ts` 中的 `showDetailsModal()`。

## 方案
### 入口位置
把“订单详情”做成一个小图标按钮，放在桌卡标题区的桌号右侧，例如：`2号桌  📋`。

### 为什么选这个位置
- 不新增一行，不挤占底部 4 个主操作位。
- 详情和“桌号/桌状态”语义更接近，比放到底部操作区更自然。
- 保留“打印”原位置，不改变现有高频操作习惯。
- 比“整张卡头可点击”更明确，减少误触和不可发现性问题。

### 点击行为
点击小图标后，打开现有的订单详情弹窗，展示当前桌活跃订单列表。

### 详情内容
弹窗里每笔订单显示：
- 订单号
- 下单时间
- 菜品明细
- 金额
- 备注（如果有）

## 实现边界
- 只给有订单的桌卡显示详情图标；空闲桌不显示。
- 不替换“打印”按钮。
- 不新增第二排按钮。
- 先复用现有详情弹窗，不新建第二套弹窗。

## 涉及文件
- `src/components/admin/TabTables.astro`
  - 在桌卡标题区增加详情图标入口
- `src/scripts/admin/table-management.ts`
  - 暴露并接通“打开详情弹窗”的触发函数
  - 在详情弹窗中补备注渲染
- `src/components/admin/AdminModals.astro`
  - 复用现有 `details-modal`
- `src/lib/admin-dashboard-utils.ts`
  - 如有必要，补桌卡层的最小详情摘要字段；优先少改，能复用现有 hidden-data 就不加新聚合结构

## 验收标准
- 桌卡底部仍然只有 4 个主按钮。
- 有活跃订单的桌卡，桌号右侧出现小详情图标。
- 点击图标能打开订单详情弹窗。
- 弹窗能看到备注内容。
- 空闲桌卡不显示该图标。
