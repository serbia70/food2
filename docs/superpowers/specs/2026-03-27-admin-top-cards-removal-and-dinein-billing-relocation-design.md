# Admin 顶部状态卡片移除与堂食订阅信息下移 Design

**Goal:** 精简 `/admin/[slug]` 页面顶部信息区，删除当前 5 个状态卡片及其容器，并把“堂食订阅提醒”从顶部移到下方费用/续费区域展示。

**Why:** 用户确认顶部这 5 个卡片“没有什么作用”，当前视觉上占用首屏空间、分散注意力，也与真正需要操作的订单区竞争位置。堂食订阅信息仍然有价值，但更适合放在费用/续费语境里统一展示，而不是单独占据顶部卡片位。

## Scope

本次只调整 admin 页面信息布局，不改底层计费逻辑：

- 删除顶部 5 个卡片：
  - 钱包余额
  - 外卖扣点门槛
  - 外卖状态
  - 堂食订阅提醒
  - 缴费提醒
- 删除承载这 5 个卡片的整块 grid 容器
- 保留顶部 MQTT 状态条和下面已有的告警/待付提醒条
- 将堂食订阅信息并入费用/续费区域（`TabRenew`）
- 不修改堂食订阅状态计算逻辑本身
- 不修改充值、扣点、锁单、账单等业务行为

## Design

### 1. 顶部区域只保留真正有即时意义的条状信息

删除当前五卡片区后，顶部只保留：

- MQTT 状态条
- 已存在的余额告警 / 欠费提醒条
- 已存在的上月佣金待付提醒条

这样首屏会更直接，用户进入页面后更快看到当前真正需要处理的内容，而不是被静态说明卡片占满横向空间。

### 2. 堂食订阅提醒并入费用/续费区域

“堂食订阅提醒”不再作为独立顶部卡片，而是作为费用/续费信息的一部分，下移到 `TabRenew`。

建议在 `TabRenew` 中新增一个堂食订阅信息块，展示当前已有的同一组数据：

- 状态
- 计费开始
- 到期日期
- 宽限截止
- 停用原因
- 堂食开关状态

这样用户在查看费用、续费、套餐状态时，可以在同一语境里看到堂食订阅信息，不再需要在页面顶部和下方来回切换。

### 3. 不保留顶部残余框体

用户明确要求“五个框框也去掉”，因此不是只隐藏内容，而是删除整块 grid 容器，避免顶部留下空白或无意义占位。
